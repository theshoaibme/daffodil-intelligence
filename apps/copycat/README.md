# CopyCat Standalone Mode

Dedicated standalone control dashboard for Daffodil Computer Use and Copycat automation.

## Features

- **Live Screen Stream**: Real-time adaptive screen view of the host machine.
- **Input Control**: Simulate clicks, drag-and-drop, scrolling, and keyboard keystrokes.
- **Macro Recorder**: Record and replay keyboard/mouse action sequences.
- **SQLite Database Integration**: Unified storage for all recorded macros.
- **Live Action Feed**: Chronological log of sent and recorded actions.
- **Recordings Manager**: View, play, rename, speed-adjust, and delete saved macros.

## Running the App

To start the standalone dashboard locally, run the following command from the root of the repository:

```bash
pnpm dev:copycat
```

Open your browser and navigate to `http://localhost:3001`.
